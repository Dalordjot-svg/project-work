# COFFEEMAN Расписание

Бот [@CoffeemanShiftsBot](https://t.me/CoffeemanShiftsBot) показывает сотруднику его смены на ближайшие семь дней. Администратор ведёт график через личный чат с ботом. На одного сотрудника можно назначить одну смену с началом в указанную дату. Если время окончания раньше времени начала, смена заканчивается на следующий день.

## Запуск на облачном сервере

1. Скопируйте файлы проекта на сервер с Docker и Docker Compose.
2. Скопируйте `.env.example` в `.env`. Укажите токен от BotFather в `BOT_TOKEN` и часовой пояс кафе в `BOT_TIMEZONE`. По умолчанию используется время Новосибирска.
3. Запустите `docker compose up -d --build`. Бот устанавливает исходящее соединение с Telegram. Входящие порты ему не нужны.
4. Напишите боту `/id` и добавьте полученный Telegram ID в `ADMIN_IDS` в файле `.env`. Несколько ID указываются через запятую. Примените изменения командой `docker compose up -d`. Откройте меню командой `/start`.
5. Попросите сотрудников нажать «Старт» в личном чате с ботом. Получите их ID командой `/staff` и назначьте смену, например `/shift 123456789 2026-12-01 09:00 18:00`. Повторная команда с тем же ID и датой заменяет смену. Для удаления используйте `/unshift 123456789 2026-12-01`.

График хранится в постоянном томе Docker `schedule-data`. Перезапуск контейнера сохраняет график. Для бота используется один запущенный экземпляр.

## Календарь в рабочей группе

1. На облачном сервере настройте HTTPS-прокси на `127.0.0.1:8765` и укажите публичный адрес (например, `https://schedule.example.com`) в `SCHEDULE_BASE_URL`. Примените настройки командой `docker compose up -d --build`.
2. Добавьте [бота](https://t.me/CoffeemanShiftsBot?startgroup=true) в рабочую группу. Назначьте бота администратором рабочей группы, чтобы Telegram гарантировал проверку членства сотрудников.
3. С аккаунта, указанного в `ADMIN_IDS`, отправьте `/schedule_on@CoffeemanShiftsBot` в группе. Бот пришлёт кнопку «Расписание». Это сообщение можно закрепить средствами Telegram.
4. Чтобы получить кнопку снова, отправьте `/schedule@CoffeemanShiftsBot`. Чтобы отозвать ссылку, отправьте `/schedule_off@CoffeemanShiftsBot`. Новое подключение выдаст новую ссылку.

Календарь показывает сетку месяца. На телефоне можно нажать на день со сменами, чтобы перейти к подробностям под сеткой. Календарь берёт график из той же базы, что и бот. Сервер проверяет подпись Telegram и членство в рабочей группе при каждом запросе календаря. При открытии сайта в обычном браузере показывается сообщение «Ты новенький?» без графика.

## Развёртывание на Render

1. В Render создайте Blueprint из ветки `main` репозитория `project-work` с файлом `render.yaml`. Конфигурация использует тариф Starter и постоянный диск на 1 ГБ.
2. В форме Render укажите `BOT_TOKEN` и `ADMIN_IDS`. Токен хранится в настройках сервиса Render. Остановите локальный процесс перед облачным запуском: один токен использует один экземпляр бота.
3. Проверьте `/healthz` по выданному Render HTTPS-адресу и отправьте боту `/start`. Откройте BotFather, выберите бота в /mybots, затем Bot Settings → Configure Mini App → Enable Mini App. Укажите HTTPS-адрес сервиса с путём /app. Кнопка в рабочем чате открывает главное Mini App через Telegram.
4. Добавьте бота в рабочую группу и отправьте `/schedule_on@CoffeemanShiftsBot`.

Первый запуск создаёт новую базу на диске Render. Если на ПК уже есть рабочие смены, перенесите копию SQLite на диск Render перед переключением команды.
